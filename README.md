# Protótipo de triagem de veículos em fim de vida

Aplicação acadêmica em Streamlit para demonstrar uma possível triagem de veículos
com maior probabilidade de estar próximos do fim de vida.

## Importante

O modelo é treinado com dados simulados e não possui validade para decisões reais.

## Publicar no Streamlit Community Cloud

1. Crie um repositório no GitHub.
2. Envie `app.py` e `requirements.txt`.
3. Acesse https://share.streamlit.io/
4. Conecte sua conta do GitHub.
5. Selecione o repositório e o arquivo `app.py`.
6. Clique em Deploy.

Depois disso, o Streamlit gera um link público para o aplicativo.
